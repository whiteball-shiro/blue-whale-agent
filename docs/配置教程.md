# 配置教程

「大肥鱼」的配置有三个入口，按常用程度排序：

| 入口 | 管什么 |
| --- | --- |
| 右键小鲸鱼 →「设置」 | 账户 / 余额、对话来源、云端 API、本地服务地址、提醒、外观、热键等**常用项** |
| 对话框内（`Alt+Q`） | Codex / 本地 / 云端切换、选模型、思考、MCP（🧩）、分流（⚡） |
| JSON 文件 | 设置界面没有的**进阶项**：外部 MCP、文件白名单、本地模型路径、ComfyUI 等 |

JSON 文件有两个：

- 主配置 `config.json`：`%APPDATA%\deepseek-whale-pet\config.json`（可运行 `setup.bat` 自动生成）
- 本地进阶 `config.local.json`：程序目录 `chat-workspace\config.local.json`（默认全关，可以不用）

模板：`config.example.json` 复制为主配置，`chat-workspace\config.local.json.example` 复制为 `config.local.json`。两个文件含 Key 与本机路径，已被 gitignore，不会上传仓库。

## 基础版（只要余额 + 云端聊天）

1. 解压到**不含中文/空格**的路径（可选运行 `setup.bat`）。
2. 右键小鲸鱼 →「设置」→ 填 API Key；云端 / 本地接口也在这个设置界面里填（见下）。
3. 按 `Alt+Q` 开对话，顶部选「云端」即可聊。

> 基础版只需要一个 Key，不需要显卡、不需要本地模型。

## 设置界面（右键小鲸鱼 →「设置」）

大部分常用配置都在这里，改动**自动保存**（停止输入约 0.5 秒），也可点「保存」或「保存并测试」。

| 分组 | 能配什么 |
| --- | --- |
| 账户 | API Key（DeepSeek 余额用）、余额名称、余额接口地址（官方留空即可，第三方兼容服务填对应接口）、自动刷新间隔（秒，0 = 关） |
| 对话与模型 | 默认对话来源（Codex / 本地 / 云端）；云端 API 地址 + Key + 模型名（任意 OpenAI 兼容：DeepSeek、OpenRouter、SiliconFlow…）；本地服务地址（预设 LM Studio `1234`、Ollama `11434`、llama.cpp/vLLM `8080`，或自定义） |
| 提醒与统计 | 低余额提醒与阈值、记录今日消耗 |
| 外观与体验 | 情绪表情、显示时间、余额弹跳、提示音、闲置半透明（含秒数）、随机语录与内容 |
| 交互 | 鼠标穿透与穿透透明度（`Ctrl+Shift+X` 可随时开关） |
| 外观定制 | 自定义鲸鱼图片 |
| 系统 | 开机自启、全局热键、打开对话快捷键（默认 `Alt+Q`）、始终置顶、任务栏 / 托盘显示位置、边缘吸附 |

这些设置最终存在主配置 `config.json` 里（键名基本一致，如 `apiKey`、`llmBaseUrl`、`chatProvider`、`displayMode`），正常使用**不用手改 JSON**。

> **本地模型小贴士**：「本地」来源接的是任意 OpenAI 兼容 `/v1` 接口（LM Studio / Ollama / llama.cpp / vLLM / LocalAI 均可）。模型下拉会自动读取：LM Studio 走 `lms ls`（自动过滤 embedding），其它服务走 `/v1/models`。
> 多模态（识图）模型要**单独放一个文件夹**：LM Studio 按同目录配对 mmproj，混放会配对错、报 `n_embd mismatch`。把主模型 `.gguf` 和配套 `mmproj-*.gguf` 放一起。

## 对话框里的开关（`Alt+Q` 打开）

- **顶部一行**：对话来源切换（Codex / 本地 / 云端）、⚡ 分流（把子任务委派给本地模型，省额度）、📷 实时共享屏幕、👁 看图、🗂 历史会话、✕ 关闭。
- **左侧悬浮竖条**：🧩 MCP 总开关；点开后竖条里会出现各工具的开关列表（文件 / 文档 / 生图 / 扩展 MCP 等）。
- **底部（输入框上方）**：模型下拉；同一带还有 🧠 思考开关、剩余上下文 token 与本地显存状态。

它们对应主配置里的 `chatProvider` / `chatMcp` / `chatLocalRoute` / `chatThinking`，在界面点一下即可生效；想「默认就开」才需要去 `config.json` 改。

## config.json 里设置界面没有的字段

| 字段 | 作用 |
| --- | --- |
| `chatCodexPath` / `chatDir` | Codex CLI 路径 / Codex 工作目录（留空自动探测） |
| `chatForceVision` | 强制把对话当「可看图」处理（null = 自动判断） |
| `localModelDir` / `localModelFilter` / `localModelId` | 本地模型目录 / 挑选关键字 / LM Studio 模型 ID（一般可留空自动） |

外部 MCP（`mcps` / `mcpServersOn`）与文件白名单相关字段见下节。

## 文件与 MCP

| 字段 | 作用 |
| --- | --- |
| `workspaceDir` | 对话工作目录（`COM:WORKSPACE` 自动解析） |
| `localWhitelist` | 文件工具**只允许**访问的目录数组，白名单外一律拒绝（在 `config.local.json` 配） |
| `mcps` | MCP 服务器数组（`id`/`name`/`command`/`args`/`env`） |
| `mcpServersOn` | MCP 开关对象，`key` = `mcps` 里条目的 `id` |

**内置（开 🧩 即用，不用配置）**：文件读写、生成 docx/pdf/pptx/xlsx、生图。

**外部 MCP 需要配**：web-search、playwright、windows-mcp、MySQL。完整可复制的 `mcps` 条目与开启方法见 [README「MCP 工具」](../README.md#mcp-工具)，要点：

- 把模板里 `command` / `args` 的 `COM:xxx` 替换成真实路径（见下节）；
- playwright / windows-mcp 能开浏览器、执行命令，MySQL 的写删改不会弹确认框——都只在信任的模型来源下开启，别给生产库开放删改。

## COM: 占位符

模板里的 `COM:xxx` 表示「这里换成你的值」：

- **自动解析，不用改**：`COM:WORKSPACE`（对话工作目录）、`COM:USERHOME`（用户主目录），可组合成 `COM:USERHOME\Documents`。
- **必须自己替换**：`COM:NODE_BIN`、`COM:WEB_SEARCH_MCP`、`COM:UVX_BIN`、`COM:LOCAL_BASE_URL`、`COM:LOCAL_MODEL_DIR` / `COM:LOCAL_MODEL_PATH` / `COM:LOCAL_MODEL_MMPROJ`、`COM:LM_STUDIO_EXE` / `COM:LMS_CLI`、`COM:COMFY_PY` / `COM:COMFY_DIR` / `COM:COMFY_CLI` 等，替换成本机真实路径/地址。

## 进阶功能（分流 / 文件 / 生图）

默认全关。开启：`Alt+Q` 打开对话 → 左侧悬浮工具条点 `🧩`（MCP）与 `⚡分流`；或在主配置把 `chatMcp` / `chatLocalRoute` 设为 `true`。前提是先建好 `chat-workspace\config.local.json`。

| 功能 | 开关/配置 | 干什么 |
| --- | --- | --- |
| 分流省额度 | `chatLocalRoute: true` | 翻译 / 总结 / 生成文档等子任务委派给本地模型 |
| 文件工具 | `chatMcp: true`（内置） | 白名单目录内读写，生成 docx/pdf/pptx/xlsx |
| 扩展 MCP | `chatMcp: true` + 外部 MCP 条目 | 网络搜索 / 浏览器 / Windows / MySQL |
| 生图 | `chatMcp: true` + ComfyUI 配置 | 本地生图，与文本模型**显存互斥**防爆显存 |

`config.local.json` 常用字段：

| 字段 | 填什么 |
| --- | --- |
| `llmBaseUrl` | 本地推理地址（同主配置 `localBaseUrl`） |
| `localModelPath` / `localModelMmproj` / `localModelDir` | 模型 gguf / mmproj / 目录 |
| `localWhitelist` | 文件工具允许的目录数组 |
| `lmStudioExe` / `lmsCli` | LM Studio 程序 / `lms.exe` 路径（留空自动探测） |
| `localLlamaExe` / `localLlamaPort` | 直启 llama 的可执行文件 / 端口（默认 `49674`） |
| `comfyPy` / `comfyDir` / `comfyCli` / `comfyPort` | ComfyUI 的 python / 目录 / 入口脚本 / 端口（默认 `8188`） |
| `localCtxSize` / `localGpuLayers` / `localThreads` / `localChatTemplate` / `localExtraArgs` | 直启文本模型的上下文 / 显存层数 / 线程 / 聊天模板 / 附加参数 |

### 生图（ComfyUI）

#### 怎么用

1. 主配置 `chatMcp: true`（或对话框左侧打开 `🧩`），并确认 ComfyUI 环境已配好（见下）。
2. 在对话框里说「画一张… / 生成一张…」即可。模型会调用内置生图工具，先弹确认框，同意后自动：停文本模型 → 启动 ComfyUI（`--lowvram`）→ 出图 → 关 ComfyUI → 恢复文本模型。全程不用手动管理 ComfyUI。
3. 图片默认保存到**桌面**（`whale-img-*.png`），ComfyUI 的 output 目录也会留一份副本。
4. 也可以手动跑同一套流程：

```powershell
powershell -File chat-workspace\whale-gpu.ps1 generate "一只猫"
powershell -File chat-workspace\whale-gpu.ps1 status   # 查看文本模型 / ComfyUI / 显存状态
```

> 生图会自动停掉本地文本模型、释放显存，完成后恢复。恢复文本模型优先用 LM Studio 的 `lms`；不用 LM Studio（如直跑 llama.cpp）就配好 `localLlamaExe` + `localModelPath`，否则生图后恢复不了文本模型。

#### 怎么配

在 `chat-workspace\config.local.json` 里填四项：

| 字段 | 填什么 |
| --- | --- |
| `comfyPy` | ComfyUI 用的 python.exe（如 ComfyUI 自带的 standalone-env） |
| `comfyDir` | ComfyUI 程序目录（含 `main.py`） |
| `comfyCli` | **生图入口脚本**：一个 python 脚本，桌宠通过 `python comfyCli --cli --prompt ...` 调用它 |
| `comfyPort` | ComfyUI 端口，默认 `8188` |

示例：

```json
"comfyPy": "D:\\ComfyUI\\python.exe",
"comfyDir": "D:\\ComfyUI",
"comfyCli": "D:\\tools\\my-comfy-cli.py",
"comfyPort": 8188
```

**关键概念**：`comfyCli` 这个脚本决定了「用哪个生图模型、节点怎么连」。仓库/发布包自带的参考实现（comfy-imagegen 的 `mcp_server.py`）是 **Qwen-Image / Anima 架构**，它把模型名写死在脚本顶部，并通过 HTTP 向 ComfyUI 提交一张节点工作流（UNETLoader + CLIPLoader(qwen_image) + VAELoader + KSampler）。换模型不是改桌宠配置，而是改这个脚本。

#### 怎么换生图模型

先分清你的目标模型和当前是不是**同一架构**：

**同架构（Qwen-Image / Anima 系）——只改文件名**

1. 下载新模型的扩散模型 / 文本编码器 / VAE 三个文件。
2. 放到 ComfyUI 对应目录：
   - 扩散模型 → `ComfyUI\models\diffusion_models\`
   - 文本编码器 → `ComfyUI\models\text_encoders\`
   - VAE → `ComfyUI\models\vae\`
3. 编辑 `comfyCli` 脚本顶部常量（示例值）：

```python
UNET_NAME = "anima-base-v1.0.safetensors"
CLIP_NAME = "qwen_3_06b_base.safetensors"
CLIP_TYPE = "qwen_image"   # 同架构一般不用动
VAE_NAME = "qwen_image_vae.safetensors"
```

改成你下载文件的文件名即可。

**不同架构（SDXL / SD1.5 / Flux 等）——节点工作流必须跟着改**

不同架构的加载器和采样参数不一样，只改文件名会直接报错或出废图。推荐做法：

1. 在 ComfyUI 界面里把新模型的工作流搭好（例如 SDXL 用 `CheckpointLoaderSimple` 加载一个 checkpoint，CLIP/VAE 都从它引出），先试出满意的图。
2. 点工作流的「导出（API 格式）」，得到一份 JSON。
3. 用这份 JSON 整体替换 `comfyCli` 脚本里的 `workflow` 字典。
4. 同时把脚本默认参数改成新模型的常用值（例如 SDXL：`cfg` 约 7、`sampler=dpmpp_2m`、`scheduler=karras`、`steps` 25~30、分辨率 768 起步；SDXL-Turbo/Lightning 则是 `cfg` 1~2、`steps` 4~8）。

想手改也可以，但必须理解节点引用。以 SDXL 为例，要点是：checkpoint 一个文件同时给出 model / clip / vae，节点引用变成 `["1",0]` / `["1",1]` / `["1",2]`，不再需要单独的 UNET/CLIP/VAE 加载器。

> 如果你的桌宠和别的程序（如 Codex 的 comfy 插件）共用同一个 `comfyCli` 脚本，建议复制一份出来改副本，再把 `config.local.json` 的 `comfyCli` 指向副本——互不影响。

**显存参考**：生图会自动以 `--lowvram` 启动 ComfyUI，但 8GB 级别显卡建议用 SD1.5 / SDXL / Qwen-Image-Anima 系的小号模型；原版 Flux、SD3.5 全家桶会非常慢或直接爆显存。换大模型前先在 ComfyUI 界面实测一张。

## 常见问题

- **余额读不到？** `apiKey` 填 DeepSeek Key，`balanceUrl` 留空走 DeepSeek 默认接口。
- **对话卡顿 / 超时？** 本地上下文别设太长；大文件先压缩；填对 `localModelDir` 才能读到上下文上限。
- **文件读不了？** 目录不在 `localWhitelist` 里，加进去即可。
- **MCP 不工作？** 检查 `chatMcp: true`、`mcpServersOn` 对应开关，以及 `COM:` 是否已替换成真实路径。
- **找不到本地模型？** 先启动本地服务并加载模型；LM Studio 走 `lms ls`，其它走 `/v1/models`。
