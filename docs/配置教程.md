# 配置教程

「大肥鱼」有两条配置线，模板随包自带：

| 文件 | 位置 | 管什么 |
| --- | --- | --- |
| 主配置 `config.json` | `%APPDATA%\deepseek-whale-pet\config.json`（可运行 `setup.bat` 自动生成） | 外观、余额、对话来源、云端/本地接口、MCP 开关 |
| 本地进阶 `config.local.json` | 程序目录 `chat-workspace\config.local.json` | 本地模型、文件白名单、ComfyUI；默认全关，可以不用 |

改法：把 `config.example.json` 复制为主配置，把 `chat-workspace\config.local.json.example` 复制为 `config.local.json`，再替换下面的字段值。两个文件含 Key 与本机路径，已被 gitignore，不会上传仓库。

## 基础版（只要余额 + 云端聊天）

1. 解压到**不含中文/空格**的路径（可选运行 `setup.bat`）。
2. 右键小鲸鱼 →「设置」→ 填 API Key；云端接口填在 `config.json`（见下）。
3. 按 `Alt+Q` 开对话，顶部选「云端」即可聊。

> 基础版只需要一个 Key，不需要显卡、不需要本地模型。

## 云端接口（任意 OpenAI 兼容）

| 字段 | 填什么 |
| --- | --- |
| `llmBaseUrl` | 接口地址，如 `https://api.deepseek.com/v1`、`https://api.openai.com/v1`；留空则没有「云端」来源 |
| `llmApiKey` | 该接口的 Key |
| `llmModel` | 模型名，如 `deepseek-chat`、`gpt-4o-mini` |

把对话来源 `chatProvider` 设为 `llm`，顶部即显示「云端」。

## 本地（不绑定具体服务）

| 字段 | 填什么 | 默认 |
| --- | --- | --- |
| `localBaseUrl` | 本地推理地址（任意 OpenAI 兼容）；LM Studio 留空即可，Ollama 填 `http://127.0.0.1:11434/v1` | LM Studio `http://127.0.0.1:1234/v1` |
| `localModelDir` | 模型目录（用于读上下文上限；留空从模型路径推导） | 空 |
| `localModelFilter` | 只挑选名字含此关键字的模型 | qwen |
| `localModelId` | 本地服务显示的模型 ID（LM Studio 用） | 空 |
| `localModelPath` | 模型文件（gguf）路径 | 占位符 |
| `localModelMmproj` | 多模态投影文件（识图用） | 占位符 |

> **多模态模型单独放一个文件夹**：LM Studio 按同目录配对 mmproj，混放会配对错、报 `n_embd mismatch`。每个能识图的模型建独立目录，把主模型 `.gguf` 和配套 `mmproj-*.gguf` 放一起。

> 模型来源自动识别：LM Studio 用 `lms ls` 列磁盘全部语言模型（自动过滤 embedding）；其它本地服务走 `/v1/models`。

## 文件与 MCP

| 字段 | 作用 |
| --- | --- |
| `workspaceDir` | 对话工作目录（`COM:WORKSPACE` 自动解析） |
| `localWhitelist` | 文件工具**只允许**访问的目录数组，白名单外一律拒绝（在 `config.local.json` 配） |
| `mcps` | MCP 服务器数组（`id`/`name`/`command`/`args`/`env`） |
| `mcpServersOn` | MCP 开关对象，`key` = `mcps` 里条目的 `id` |

**内置（开 🧩 即用，不用配置）**：文件读写、生成 docx/pdf/pptx/xlsx、生图。

**外部 MCP 需要配**：web-search、playwright、windows-mcp、MySQL。完整可复制的 `mcps` 条目与开启方法见 [README「MCP 工具」](../README.md#mcp-工具)，要点：

- 把模板里 `command` / `args` 的 `COM:xxx` 替换成真实路径（见下节）；
- playwright / windows-mcp 能开浏览器、执行命令，MySQL 的写删改不会弹确认框——都只在信任的模型来源下开启，别给生产库开放删改。

## COM: 占位符

模板里的 `COM:xxx` 表示「这里换成你的值」：

- **自动解析，不用改**：`COM:WORKSPACE`（对话工作目录）、`COM:USERHOME`（用户主目录），可组合成 `COM:USERHOME\Documents`。
- **必须自己替换**：`COM:NODE_BIN`、`COM:WEB_SEARCH_MCP`、`COM:UVX_BIN`、`COM:LOCAL_BASE_URL`、`COM:LOCAL_MODEL_DIR` / `COM:LOCAL_MODEL_PATH` / `COM:LOCAL_MODEL_MMPROJ`、`COM:LM_STUDIO_EXE` / `COM:LMS_CLI`、`COM:COMFY_PY` / `COM:COMFY_DIR` / `COM:COMFY_CLI` 等，替换成本机真实路径/地址。

## 进阶功能（分流 / 文件 / 生图）

默认全关。开启：`Alt+Q` 打开对话 → 左侧悬浮工具条点 `🧩`（MCP）与 `⚡分流`；或在主配置把 `chatMcp` / `chatLocalRoute` 设为 `true`。前提是先建好 `chat-workspace\config.local.json`。

| 功能 | 开关/配置 | 干什么 |
| --- | --- | --- |
| 分流省额度 | `chatLocalRoute: true` | 翻译 / 总结 / 生成文档等子任务委派给本地模型 |
| 文件工具 | `chatMcp: true`（内置） | 白名单目录内读写，生成 docx/pdf/pptx/xlsx |
| 扩展 MCP | `chatMcp: true` + 外部 MCP 条目 | 网络搜索 / 浏览器 / Windows / MySQL |
| 生图 | `chatMcp: true` + ComfyUI 配置 | 本地生图，与文本模型**显存互斥**防爆显存 |

`config.local.json` 常用字段：

| 字段 | 填什么 |
| --- | --- |
| `llmBaseUrl` | 本地推理地址（同主配置 `localBaseUrl`） |
| `localModelPath` / `localModelMmproj` / `localModelDir` | 模型 gguf / mmproj / 目录 |
| `localWhitelist` | 文件工具允许的目录数组 |
| `lmStudioExe` / `lmsCli` | LM Studio 程序 / `lms.exe` 路径（留空自动探测） |
| `localLlamaExe` / `localLlamaPort` | 直启 llama 的可执行文件 / 端口（默认 `49674`） |
| `comfyPy` / `comfyDir` / `comfyCli` / `comfyPort` | ComfyUI 的 python / 目录 / 入口脚本 / 端口（默认 `8188`） |
| `localCtxSize` / `localGpuLayers` / `localThreads` / `localChatTemplate` / `localExtraArgs` | 直启文本模型的上下文 / 显存层数 / 线程 / 聊天模板 / 附加参数 |

### 生图（ComfyUI）

1. 装好 ComfyUI 和生图模型（如 Anima / Qwen-Image）。
2. 在 `config.local.json` 填 `comfyPy`、`comfyDir`、`comfyCli`（如 `mcp_server.py`），端口默认 `8188`。
3. 主配置 `chatMcp: true`，对话框里让它生图即可；也可手动跑 `powershell -File chat-workspace\whale-gpu.ps1 generate "一只猫"`。

> 生图会自动停掉本地文本模型、释放显存，完成后恢复。恢复文本模型优先用 LM Studio 的 `lms`；不用 LM Studio（如直跑 llama.cpp）就配好 `localLlamaExe` + `localModelPath`，否则生图后恢复不了文本模型。

## 常见问题

- **余额读不到？** `apiKey` 填 DeepSeek Key，`balanceUrl` 留空走 DeepSeek 默认接口。
- **对话卡顿 / 超时？** 本地上下文别设太长；大文件先压缩；填对 `localModelDir` 才能读到上下文上限。
- **文件读不了？** 目录不在 `localWhitelist` 里，加进去即可。
- **MCP 不工作？** 检查 `chatMcp: true`、`mcpServersOn` 对应开关，以及 `COM:` 是否已替换成真实路径。
- **找不到本地模型？** 先启动本地服务并加载模型；LM Studio 走 `lms ls`，其它走 `/v1/models`。
