DeepSeek 余额桌宠

API Key 只保存在本机。所有功能均可随时开关。

账户

官方 DeepSeek 留空即可；第三方兼容服务填它的余额接口地址。
每多少秒自动刷新余额，默认 30；填 0 关闭自动刷新。

对话与模型

打开对话框时默认用的来源，可在对话里随时切换。
任意 OpenAI 兼容接口；DeepSeek / OpenRouter / SiliconFlow 等均可。留空则云端来源不可用。
「本地」来源连接的就是一个 OpenAI 兼容接口——LM Studio、Ollama、llama.cpp、vLLM、LocalAI 等只要提供 /v1 接口都行。选上方预设即自动填地址，或直接手填；留空用 LM Studio 默认（1234）。

提醒与统计

余额低于这个数值（默认 ¥5）时提醒。

外观与体验

多少秒无操作后变淡（默认 5 秒）。

交互

开启后鼠标会穿透小鲸鱼点到后面的窗口，小鲸鱼同时变淡一些。穿透后可用托盘图标或 Ctrl+Shift+X 随时关闭。

外观定制

建议 1026×1026 的 PNG，气泡位置需与原图一致（中心 455,247）。

系统

全局快捷键，按下打开对话气泡，再按一次关闭。格式如 Alt+Q、Ctrl+Shift+O、Ctrl+Alt+C；留空用默认 Alt+Q。
此选项只影响任务栏/托盘图标，与桌宠本体无关——小鲸鱼始终显示在桌面，是否置顶由上方「始终置顶」控制。
